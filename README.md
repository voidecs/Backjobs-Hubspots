# BACKJOBS Manager Dashboard

A React + Vite implementation of the BACKJOBS manager dashboard shown in the reference image.

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Included

- Manager dashboard UI
- Sidebar navigation
- KPI cards
- Revenue trend SVG chart
- Pipeline donut chart
- Department bar chart
- Recent deals
- High-priority tickets
- Jira engineering issues
- Resolution/performance metrics
- Switch Role dropdown (Manager, Sales, Developer / Support, Customer)

This version uses mock data for the UI stage. Do not add a local CRM database. Later, replace mock values with HubSpot, Freshdesk, and Jira API data through the backend integration layer.
